Le projet

Landguard Alert vise à améliorer la gestion des conflits fonciers dans la région Maritime du Sud-Togo en centralisant les données cadastrales, les plaintes, les litiges et les décisions judiciaires dans un système cartographique accessible via le web.

Fonctionnalités principales

Cartographie

Visualisation interactive des parcelles et repérage rapide des zones de litige.

Plaintes

Enregistrement, suivi et association des dossiers à une parcelle précise.

Litiges

Suivi des statuts, historique et clôture des procédures selon leur évolution.

Alertes

Notification automatique lors d’un événement important sur une parcelle.

Décisions

Gestion des décisions judiciaires et transmission aux acteurs concernés.

Tableau de bord

Indicateurs clés, statistiques et synthèses pour piloter les dossiers.

Architecture proposée

  • Frontend : interface Web et cartographie interactive
  • Backend : gestion des utilisateurs, plaintes, litiges et alertes
  • Base de données : PostgreSQL + PostGIS
  • Cartographie : GeoServer / OpenLayers
  • API : REST pour les échanges entre services
